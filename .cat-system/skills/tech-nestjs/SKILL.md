# NestJS runtime constraints

Check the adopted package versions and locked dependencies. Verify the built module can initialize with the actual NestFactory, listen on disposable loopback and dispatch a real bound route; verify scoped HTTP tests for the actual admitted functionality. Do not treat successful compilation, package presence or a health response alone as application conformance. `cat_node_service_technology.py` supplies the limited live module/route probe together with source-bound named service-test evidence. Never run it against a production database or endpoint. Authentication, transactions, PI and Process interactions require their own evidence.
